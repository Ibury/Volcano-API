# Python Flask Server for Volcanic Maps Visualization

This repository contains the source code for the Python Flask server responsible for serving the volcanic map viewer of the Geo3bcn - CSIC institute and the data visualization portal for EPOS.

## Dependencies
```
sudo apt-get install python3
sudo apt install python3-pip -y
sudo apt install openssl
```
## Installation

To install the Python dependencies, go to the directory where the source files are located and execute, either under python base or a virtual environment:

```
pip install -r requirements.txt
```
Then, install GDAL and its dependencies using these commands:
```
sudo apt-get install gdal-bin
sudo apt install libgdal-dev
```
You’ll also need to export a couple of environment variables for the compiler:
```
export CPLUS_INCLUDE_PATH=/usr/include/gdal
export C_INCLUDE_PATH=/usr/include/gdal

```
Check the version:
```
gdal-config --version
```

Install the showed version from pip:
```
pip install gdal==3.4.1
pip install gdal2tiles
```

## Configuration

To configure the server, fill in the fields of your choice in the config.ini file. 

You can copy volcanoes folder from https://gitlab.geo3bcn.csic.es/geo-inquire/volcano-web-server.git.

To generate a self-signed certificates, you can use these commands:

Generate Private Key (.key):

```
openssl genpkey -algorithm RSA -out server.key -aes256
```
Generate Self-Signed Certificate (.pem):
```
openssl req -x509 -sha256 -nodes -days 365 -key server.key -out server.crt
```
You can also configure the logging options in the logging.conf file. This is an example of config.ini file:

```
# Paths configuration
[paths]
# Directories for various file types
volcano = /var/www/geoinquire/volcanoes/
type = types/
incoming = temp/incoming/
temp = temp/
version = temp/old/
trash = temp/trash/

# SSL Certificates
# IMPORTANT: DEBUG = True
#These fields are sensitive and should be set in a secure manner.
#            Consider using environment variables or a secure vault for storing these values.
#            The paths below are examples. Make sure to point to the correct certificate files.
crt =  /var/www/mydomain_cert.pem
key =  /var/www/mydomain_key.key

# Webserver configuration
[webserver]
# Domain and port settings
# Specify the host domain or IP address. If not set, 'localhost' will be used.
# Examples for the host field are provided in the comments.
host = 127.0.0.1
port = 5000
DEBUG = True

# Flask specific configurations
[flask]
# Server name and debug settings
SERVER_NAME = 'localhost:8888'

# Configuración de Flask
#DEBUG = True  # Activa el modo de depuración
#SWAGGER_UI_DOC_EXPANSION = 'none'  # Expandir la documentación de Swagger
#RESTX_VALIDATE = True  # Activar la validación de entradas RESTx
#RESTX_MASK_SWAGGER = False  # Desactivar la máscara de Swagger en RESTx
#RESTX_ERROR_404_HELP = False  # No mostrar ayuda en caso de errores 404 en RESTx
```

## Execution

IMPORTANT: Run these commands inside API's folder:

To run the development server, execute:

```
python app.py
```
To run the production server, install:
```
pip install gunicorn
```
Now execute:
```
gunicorn -w 4 --bind 127.0.0.1:8080 --certfile /path/to/mydomain_cert.pem --keyfile /path/to/mydomain_key.key '__init__:create_app("","./config.ini")'
```
## Documentation

Once the service is started, you can access the autogenerated documentation and test the different endpoints through the URL {host}:{port}/api, for example in development: https://localhost:5000/api and in production: https://localhost:8080/api
